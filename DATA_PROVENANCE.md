# Data provenance and availability

Dataset filename: `PRSA_data_2010.1.1-2014.12.31.csv`

The dataset file supplied with the project is stored locally in `data/`. It contains 43,824 hourly observations covering 2010-01-01 00:00 through 2014-12-31 23:00. The PM2.5 target has 2,067 missing values (4.717%).

Before public redistribution, verify the original dataset source, citation requirements, and license/terms. Do not assume that inclusion in this working project grants redistribution rights.
